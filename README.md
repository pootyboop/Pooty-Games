# Pooty Games!
- Multiplayer party games for 2+ players, including original games and remakes of classics. Sorta like a personal minigame server as a world you host for you and your friends.

## How to Download
- Scroll up to the top of this page and click "Code", then "Download ZIP".
- Once it's downloaded, extract the ZIP and drag the folder into your Minecraft saves folder. Have fun!

## Details
- Minecraft Java Edition 1.21.4
- Play with friends via LAN or a server (make sure cheats/command blocks are enabled!) I recommend [e4mc]([url](https://modrinth.com/mod/e4mc)), a mod that lets you host LAN worlds that people anywhere in the world can join.
- More info on [my website](https://elliotgmann.com/projects/pooty-games).
